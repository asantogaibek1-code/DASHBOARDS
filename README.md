# 🐼 Свод мероприятий

Интерактивный дашборд для отслеживания мероприятий по 7 организациям с визуализацией данных, поддержкой двух языков (русский/казахский) и двух тем (светлая/тёмная).

## ✨ Возможности

- **Диаграммы**: визуализация распределения мероприятий по организациям
- **Организации**: детальные карточки для каждой организации
- **Таблицы данных**: редактируемые таблицы с мгновенным обновлением диаграмм
- **Два языка**: русский (RU) и казахский (KZ)
- **Две темы**: светлая и тёмная с плавным переключением
- **Авторизация**: защита редактирования данных паролем
- **Адаптивность**: оптимизация для мобильных устройств
- **Автосохранение**: данные сохраняются в localStorage

## 🚀 Развёртывание на GitHub Pages

### Способ 1: Автоматический деплой через GitHub Actions

1. Загрузите проект в репозиторий GitHub
2. Создайте файл `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      
      - name: Install dependencies
        run: npm ci
      
      - name: Build
        run: npm run build
      
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

3. В настройках репозитория (Settings → Pages) выберите:
   - Source: Deploy from a branch
   - Branch: gh-pages / root

### Способ 2: Ручной деплой

```bash
# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Папка dist готова к загрузке на GitHub Pages
```

Загрузите содержимое папки `dist` в ветку `gh-pages` или настройте GitHub Pages на папку `/docs`.

## 🔐 Доступ к редактированию

Для редактирования данных в таблицах необходимо войти в систему:

1. Нажмите кнопку **"Вход"** в шапке сайта
2. Введите пароль: `ktomemeSCOME`
3. После входа появится возможность редактировать все значения

## 📊 Организации

- **KMU** — Карагандинский медицинский университет
- **KazNMU** — Казахский национальный медицинский университет
- **AMU** — Евразийский национальный университет
- **KRMU** — Карагандинский государственный медицинский университет
- **MKTU** — Карагандинский технический университет
- **SMU** — Семейский медицинский университет
- **ZKMU** — Западно-Казахстанский государственный медицинский университет

## 🛠 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS v4** — стилизация
- **SVG** — векторная графика (панды, диаграммы)

## 📱 Адаптивность

Сайт полностью адаптирован для:
- Десктопов (1920px+)
- Планшетов (768px - 1024px)
- Мобильных устройств (320px - 767px)
