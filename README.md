# 🐼 Свод мероприятий

Интерактивный дашборд для отслеживания мероприятий по 7 организациям с визуализацией данных, поддержкой двух языков (русский/казахский) и двух тем (светлая/тёмная).

## ✨ Возможности

- **Диаграммы**: визуализация распределения мероприятий по организациям
- **Организации**: детальные карточки для каждой организации
- **Таблицы данных**: редактируемые таблицы с мгновенным обновлением диаграмм
- **Два языка**: русский (RU) и казахский (KZ)
- **Две темы**: светлая и тёмная с плавным переключением
- **Авторизация**: защита редактирования данных паролем
- **Адаптивность**: оптимизация для мобильных устройств
- **Автосохранение**: данные сохраняются в localStorage

## 📊 Организации

- **KMU** — Карагандинский медицинский университет
- **KazNMU** — Казахский национальный медицинский университет
- **AMU** — Евразийский национальный университет
- **KRMU** — Карагандинский государственный медицинский университет
- **MKTU** — Карагандинский технический университет
- **SMU** — Семейский медицинский университет
- **ZKMU** — Западно-Казахстанский государственный медицинский университет

## 🛠 Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS v4** — стилизация
- **SVG** — векторная графика (панды, диаграммы)

## 📱 Адаптивность

Сайт полностью адаптирован для:
- Десктопов (1920px+)
- Планшетов (768px - 1024px)
- Мобильных устройств (320px - 767px)

## 🎨 Особенности

- **Маскот**: милая панда в логотипе и фоновых силуэтах
- **Анимации**: плавные переходы между темами, анимированные диаграммы
- **Производительность**: оптимизация для мобильных устройств
- **Доступность**: семантическая разметка, ARIA-атрибуты
